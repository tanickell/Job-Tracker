### Job Description

**Software Engineering Intern — Vault Studios ABQ**  
**Internship length: 135 hours**

The Software Engineering Intern will help develop and improve software supporting Vault Studios’ creative production workflows and emerging technology projects. Under technical supervision, the intern will work on scoped assignments involving web applications, workflow tools, or interactive systems.

**Responsibilities include:**

- Assist with designing, coding, and improving assigned application features.
    
- Help connect interfaces, APIs, and data storage as appropriate to the project.
    
- Investigate bugs, test functionality, and document results.
    
- Use version control and participate in code reviews.
    
- Create technical documentation and user instructions.
    
- Track assigned tasks, progress, and internship hours.
    

### Qualifications

You must be a credit-bearing CNM student enrolled in a program with an internship course to qualify for this internship. Not sure if your program has an internship course? Email internships@cnm.edu to find out. CNM Ingenuity learners are not eligible for this internship. You will be provided a stipend of \$765 per credit hour you register for, so for a 3 credit internship course, you will receive a \$2,295 stipend upon successful completion of the internship.
