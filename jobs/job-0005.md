### Job Description

**Description**

Leidos is looking for a Junior Software Engineer Intern to join a high performing agile team to support a nationally significant and fast-paced management programs. The Leidos team is focusing on full stack development of user interfaces, restful services, APIs, database scripting, AWS Cloud infrastructure, and integration of micro-services.

**Primary Responsibilities**

- The Junior Software Engineer Intern needs to be local to Tucson and will be responsible for software development activities both individually and as a member of the an agile team.
    
- The intern will be mentored by Senior Staff through program increment planning, industry standards, and related development activities.
    
- The individual will analyze and study complex system requirements, use design software tools, provide support using formal specifications, data flow diagrams, and other accepted design techniques with the help of other team members.
    
- The individual will be mentored through software engineering principles and standards to ensure that developed code is modifiable, efficient, reliable, understandable, fault tolerant, modular and reusable.
    
- The individual will be assigned various tasks across the program's full stack to help gain experience, knowledge and application of object orientating programming languages.
    

**Basic Qualifications**

- Working towards a Bachelors' degree in Computer Science, Mathematics, or similar discipline.
    
- Knowledge of, exposure and/or experience working with software design patterns and Web Application Development.
    
- Knowledge of, exposure and/or experience using some of the following Programming Languages and tools: Java, JavaScript, Typescript, Python, C++, SQL
    
- Familiarity with one or more of the following Development Frameworks: React, Svelte, Vue, Django, SpringBoot, Flask, FastAPI, NodeJS
    
- Self-motivated to learn and apply themselves to problem solving
    
- Familiarity with GIT standards
    
- Must be able to obtain and maintain a TS/SCI with Polygraph clearance
    
- US Citizenship required
    
- Must be able to commute to or is located in the Tucson area
    

**Preferred Qualifications**

- Some experience developing front end user interface frameworks either through side projects or relevant work experience
    
- Familiarity with working in an agile environment
    
- Familiarity with working on Full Stack Development
